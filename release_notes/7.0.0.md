# Jasmine NPM 7.0.0 Release Notes

## Summary

This is a major release that includes breaking changes. It updates jasmine-core
to 7.0.0. In addition to the list of breaking changes below, be sure to read the
[release notes for `jasmine-core` 7.0.0](https://github.com/jasmine/jasmine/blob/main/release_notes/7.0.0.md).
You may also find the
[upgrade guide](https://jasmine.github.io/upgrade-guides/7.0) helpful.

## Breaking changes

* The `alwaysListPendingSpecs` config option is no longer supported. Set 
  `defaultReporter: { alwaysListPendingSpecs: ... }` instead. †
* The redundant `showColor` and `alwaysListPendingSpecs` methods from the
  `Jasmine` and `ParallelRunner` classes have been removed. Call 
  `.configureDefaultReporter()` with the `color` and/or `alwaysListPendingSpecs`
  options set instead.†
* Multiple calls to `Jasmine#alwaysListPendingSpecs` and
  `ParallelRunner#alwaysListPendingSpecs` are no longer ignored. †
* Redundant configuration properties that were deprecated in 6.3.0 have been
  removed. Use the corresponding env config properties instead, e.g.
  `env.random` instead of `random`.
* The jsLoader config setting has been removed. The default loader now covers
  most use cases for it. If you find that the default loader still doesn't meet
  your needs, use a custom loader.
* `Jasmine#loadConfig` and `ParallelRunner#loadConfig` are now async.

## New features

* `--list-not-applicable` CLI flag †
* [Custom loaders](https://jasmine.github.io/api/npm/7.0/Configuration.html#loader)
  allow replacing the built-in module loading logic with your own.

† New since 7.0.0-pre.2

## Supported environments

This version has been tested on Node 20*, 22, 24, and 26.

\* Supported on a best-effort basis. Support may be dropped if it becomes 
impractical, and bugs affecting only this version may not be treated as release
blockers.
